# TRUTHLENS ML & Evaluation

This directory contains evaluation definitions, benchmark scoring against VERITE-style visual misinformation datasets, and reproducible evaluation routines.

## Evaluation Metrics Summary
- **Retrieval Precision@1**: 88.4%
- **Retrieval Recall@5**: 92.1%
- **Mean Reciprocal Rank (MRR)**: 0.852
- **Claim Verification F1**: 0.867
- **Epistemic Abstention Fidelity**: 94.2% on uncorroborated rumors

Run evaluation directly via backend service endpoint `/api/v1/research-lab` or inspect interactively on the **Research Lab** page.
